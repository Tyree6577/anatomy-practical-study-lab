# Anatomy Practical Study Lab

Open the website at https://Tyree6577.github.io/anatomy-practical-study-lab/

Three written-answer practice exams, 50 questions and 100 points each, with automatic grading, spelling deductions, manual overrides and browser-local attempt history.

`index.html` is the complete standalone website: styles, application code, grading rules, images and original printable PDFs are embedded. Download it and open it locally to study offline. There are no dependencies or build steps. Browser storage is separate for this website, the original Sites address, and downloaded copies.

Correct/equivalent answers receive 2 points; minor spelling errors 1.5; larger recognizable spelling errors 1.25; wrong/blank answers 0. Uncertain wording is marked for manual review. This deterministic policy approximates the teacher's spelling rubric. Original printable PDFs retain the earlier 50-point rubric and are labeled accordingly.

To update the website, replace index.html with a newly generated standalone version and commit to main. GitHub Pages publishes from main, / (root). No student answers or saved attempts are included in this repository.

The original hosted website remains at https://anatomy-practical-study-lab.dawsontyree89.chatgpt.site/

Course-material references and image credits appear in the instructor panel and embedded instructor packet.
